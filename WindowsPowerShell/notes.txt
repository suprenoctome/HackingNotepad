Cmdlets follow a consistent Verb-Noun naming convention. This structure makes it easy to understand what each cmdlet does. 
The Verb describes the action, and the Noun specifies the object on which action is performed. For example:

Get-Content: Retrieves (gets) the content of a file and displays it in the console.
Set-Location: Changes (sets) the current working directory.


1. Basic Cmdlets:

Get-Command - List all cmdlets
	-CommandType "Function" - List all cmdlets of type Function
	-Name "pattern*" - Finds cmdlet using name pattern
Get-Help - Provides details about cmdlets
	-examples - Provides examples of cmdlet use
Get-Alias - Lists all aliases
Find-Module -Name "PowerShell*" - Search for a module across online repositories
Install-Module -Name "PowerShellGet" - Installs a module

2. Filesystem Cmdlets:

Get-ChildItem
Set-Location -Path ".\Documents"
New-Item -Path ".\captain-cabin\captain-wardrobe" -ItemType "Directory"
Remove-Item -Path ".\captain-cabin\captain-wardrobe"
Copy-Item -Path .\captain-cabin\captain-hat.txt -Destination .\captain-cabin\captain-hat2.txt
Get-Content -Path ".\captain-hat.txt"

3. Piping, Filtering, Sorting Data:

Select-String -Path ".\captain-hat.txt" -Pattern "hat"
Get-ChildItem | Sort-Object Length
Get-ChildItem | Where-Object -Property "Extension" -eq ".txt"
	-eq: "equal to"
	-ne: "not equal"
	-gt: "greater than"
	-ge: "greater than or equal to"
	-lt: "less than"
	-le: "less than or equal to"
Get-ChildItem | Where-Object -Property "Name" -like "ship*"

4. System and Network information

Get-NetIPConfiguration - Basic network interfaces informations
Get-NetIPAddress - Details about network
Get-Process - List all processes
Get-Service - List all services
Get-NetTCPConnection - List active network connections
Get-FileHash -Path .\ship-flag.txt - Returns file hash

5. Scripting

Invoke-Command - Runs commands on local and remote computers.

------------- Example 1: Run a script on a server -------------

Invoke-Command -FilePath c:\scripts\test.ps1 -ComputerName Server01

--------- Example 2: Run a command on a remote server ---------

Invoke-Command -ComputerName Server01 -Credential Domain01\User01 -ScriptBlock { Get-Culture }
